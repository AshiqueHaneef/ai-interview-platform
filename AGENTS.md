# AI Interview Platform

Real-time AI mock-interview practice: LLM interviewer over WebSockets, RAG over a question bank, optional voice loop (Whisper STT / TTS), and rubric-based structured scoring.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `AshiqueHaneef/ai-interview-platform` (uses the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
